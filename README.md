# Download speed test

Консольный скрипт на Python, который скачивает содержимое указанного URL
**10 раз последовательно**, дожидаясь полного ответа на каждый запрос,
и выводит среднее время запроса, суммарный объём данных и скорость загрузки.
Внешние зависимости не нужны.

## Запуск

Требуется Python 3.10 или новее.

```bash
git clone https://github.com/97Dmitry/download-speed-test.git
cd download-speed-test
python3 speed_test.py 'https://example.com/large-image.jpg'
```

Замените пример на прямой URL доступного файла. В Windows вместо `python3`
можно использовать `py -3`.

Необязательный тайм-аут операций сокета (по умолчанию 30 секунд):

```bash
python3 speed_test.py 'https://example.com/large-image.jpg' --timeout 60
```

Это тайм-аут отдельной блокирующей сетевой операции, а не лимит времени
всего запроса: большая загрузка может длиться дольше.

Пример формата вывода (числа условные):

```text
Requests completed: 10
Average request time: 0.500 s
Total downloaded: 10485760 bytes (10.000 MiB)
Download speed: 2.000 MiB/s
```

## Как считается результат

- Время каждого запроса измеряется через `time.perf_counter()` от начала
  обращения до полного чтения тела ответа. Оно включает установление соединения,
  ожидание сервера и загрузку; при перенаправлениях — также их обработку.
- Среднее время: `сумма времени 10 запросов / 10`.
- Объём: сумма фактически прочитанных байтов тел ответов, без HTTP-заголовков
  и транспортных накладных расходов.
- Скорость: `суммарные байты / суммарное время в секундах / 1024²`.
  Единица — **MiB/s (мебибайты в секунду)**, 1 MiB = 1 048 576 байт.
  Это отношение общего объёма ко времени, а не среднее арифметическое скоростей.

Ответ читается блоками по 64 KiB и не сохраняется в память целиком или на диск.
Скрипт отправляет `Accept-Encoding: identity` и `Cache-Control: no-cache`;
промежуточные серверы могут не соблюдать эти указания. HTTP/HTTPS
перенаправления обрабатываются стандартной библиотекой, сертификаты HTTPS
проверяются. Используются стандартные настройки прокси из окружения.

При сетевой ошибке, HTTP-ошибке или неполном ответе с `Content-Length`
скрипт пишет сообщение в stderr и завершается с кодом 1 без итоговой статистики.
Повторных попыток нет. Ошибки аргументов дают код 2, Ctrl+C — 130.
Если сервер не указал длину тела, нештатный обрыв, выглядящий как обычный конец
ответа, определить нельзя.

## Ограничения

Результат показывает скорость загрузки **с выбранного сервера**, а не гарантированную
пропускную способность интернет-канала. На него влияют задержки, нагрузка сервера,
кэширование, прокси и другие загрузки. Для замера лучше использовать достаточно
большой статический файл. Скрипт скачает его десять раз: файл размером 100 MiB
потребует примерно 1 GiB трафика. URL должен возвращать сам файл, а не HTML-страницу
ссылки на скачивание.

## Проверка

```bash
python3 -m unittest -v
```

Тесты поднимают локальный HTTP-сервер; внешний интернет не требуется.
Проверяются десять полных ответов, точность расчётов при управляемых часах,
вывод CLI, ошибочные аргументы, HTTP 503 и неполное тело ответа.
